# Manifest

## Included

- Local simulator source code: `local_mission_sim/src/msar_sim/`
- Local run scripts: `local_mission_sim/run_demo.py`, `local_mission_sim/run_experiments.py`
- Neural-Q training script: `local_mission_sim/train_neural_q.py`
- Local requirements: `local_mission_sim/requirements.txt`
- Unit test: `local_mission_sim/tests/test_demo.py`
- Remote AUV-6DOF MARL entry: `remote_auv6dof_marl/auv6dof_marl_entry.py`

## Excluded

- Python virtual environments.
- Bytecode caches and test caches.
- Regenerated experiment outputs.
- Operating-system metadata files.
- Manuscript build artifacts.
- Machine-specific paths, account names, and credentials.
